# Social brand icons

The contact section uses local SVG files in `public/images/brands/`. No external icon requests are made when visitors open the site.

These are brand glyphs distributed by Simple Icons, not assets downloaded directly from the platform owners. Simple Icons distributes its SVG collection under CC0; the brands retain their trademarks.

| File | Download source | Brand resources |
| --- | --- | --- |
| facebook.svg | https://cdn.simpleicons.org/facebook | https://www.meta.com/brand/resources/facebook/logo/ |
| instagram.svg | https://cdn.simpleicons.org/instagram | https://www.meta.com/brand/resources/instagram/instagram-brand/ |
| youtube.svg | https://cdn.simpleicons.org/youtube | https://www.youtube.com/howyoutubeworks/resources/brand-resources/ |
| tiktok.svg | https://cdn.simpleicons.org/tiktok | https://developers.tiktok.com/doc/getting-started-design-guidelines/ |

TikTok and Douyin use the shared musical-note glyph. The SVG artwork is preserved as downloaded. Platform names and accessible labels are supplied by the contact links.

Interface icons (arrows, mail, menu, playback controls) use `@lucide/vue`. Brand icons are kept separate because Lucide v1 no longer includes them.
